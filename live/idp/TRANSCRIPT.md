## The same removal when no sync runs: the ID-token lifespan is the window

```text
ID-token lifespan 8s. anna signs in, delegates support-agent, and is removed from /employees/support in Keycloak
0.9s after her sign-in. No sync runs, nobody calls revoke.
  a new sign-in: DELEGATE-ROLE-NOT-HELD (the fresh ID token has no groups claim)
  the OLD ID token replayed every 0.25s: 28 new agent tokens under support-agent, until it expired.
  MEASURED REPLAY WINDOW WITHOUT A SYNC: 7.1s after the removal = the rest of the ID token's lifetime
  (at most 8s here; at most 300s with Keycloak's default lifespan).
  The agent tokens issued in that window keep working after it (DELEGATE-POLICY-PERMIT, ttl 900s, role max_ttl 900s)
  until they expire or `sync --revoke` / `token revoke --user anna` runs: DELEGATE-TOKEN-REVOKED.

Worst case if the sync never runs: ID-token lifespan + role max_ttl after the removal (300s + 900s with these defaults).
With the sync running every N seconds with --revoke: at most N (plus the sync's own run time), for new and for live tokens.
```
