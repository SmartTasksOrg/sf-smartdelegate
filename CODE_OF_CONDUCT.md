# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The linked text applies to every project space: issues, pull requests,
discussions and review.

## Reporting

Report conduct problems to the maintainers in [MAINTAINERS.md](MAINTAINERS.md).
There is no dedicated conduct mailbox; use the private vulnerability reporting
form (SECURITY.md) and say the report is about conduct.
Maintainers keep the reporter's identity confidential.
