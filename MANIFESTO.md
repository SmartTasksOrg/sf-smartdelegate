# The SmartDelegate Code

*In the voice of The Pangolin Code — bold in the open, disciplined where it counts.*

**I. Close the gap at the moment it bites.**
SmartDelegate fires when a human hands work to an agent: lend one role, for one task, and nothing else.

**II. Work on clone.**
A tool that needs setup before it proves itself doesn't spread. Ship the demo.

**III. Same seal, same family.**
`DELEGATE-*` rules, one mascot, one manifesto. Kin, not clones.

**IV. Conform, then compose.**
Meet the IAIso §10 · Delegation bar, then stack with every sibling tool and with the IAM you already run.

**V. Bare it all — except the secrets.**
Radical in the open (smartdelegate/), locked where it counts (private/). Say what was tested and what was not.
